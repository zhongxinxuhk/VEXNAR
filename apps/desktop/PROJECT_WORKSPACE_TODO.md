# VEXNAR 桌面端项目工作台 TODO

左栏负责全局导航，中间负责推进当前任务，右栏显示当前项目的任务详情、会话和证据。打开任务后，中间默认聚焦主 Agent，右栏同步打开任务详情。多 Agent 的委派、依赖、结果与验证都从主线上的具体步骤进入。

首版关键路径为「选项目 → 打开任务 → 看主 Agent 当前步骤 → 打开工具或流量证据 → 返回原步骤」。任务详情参考本机 Web 路由 `/function/tasks/detail?id=1237`。

每条交付完成并通过对应检查后，将 `- [ ]` 改为 `- [x]`。验收项在实际执行并通过后单独勾选，可在条目下补充命令、用例或记录。遇到阻塞时保留未勾选状态，并在条目下记录原因。

## P3 多 Agent 分支协作

- [ ] 在主线展示汇总采用的分支结果和对应执行记录。结论冲突时显示冲突点与复核状态，最终交付引用实际完成的验证。
