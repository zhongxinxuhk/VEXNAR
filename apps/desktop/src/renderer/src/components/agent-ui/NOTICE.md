# Motif-derived interface patterns

The components in this folder adapt interface patterns from **Motif** —
<https://motif.sweetretry.com> / <https://github.com/SweetRetry/motif> — to
VEXNAR's own design tokens, data contracts and interaction rules. They are
rewritten for the desktop renderer rather than copied verbatim, and the original
MIT notice is retained below.

- Activity Heatmap — `<ActivityHeatmap />`
- Breakdown — `<Breakdown />`
- Approval Card — `<ApprovalCard />`
- Thinking Block — `<ThinkingBlock />`
- Tool Call — `<ToolCallRow />`
- Loading State — `<AgentLoadingMark />` / `<AgentLoading />`
